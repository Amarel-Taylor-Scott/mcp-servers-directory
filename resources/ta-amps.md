# ta-amps projects and seed packs

[Browse all 113 packs in the searchable CSV](ta-amps-seedpacks.csv). Each row links to a pack guide and its manifest at the revision reviewed on November 21, 2026. A **Task Object** is a reusable input, procedure or piece of evidence. A **Task** describes work a worker can claim. The 113 packs contain 1,860 Task Object templates and 596 Task templates.

The upstream descriptor lists public HTTP MCP access to Fabric, Herma and Eranos through **December 31, 2026**. Check the current descriptor before connecting after that date. In this directory, `mcp-dir search ta-amps` returns those three services. Search pack IDs, titles and upstream summaries with `mcp-dir search --scope packs`. For example, `mcp-dir search "sidechain pause" --scope packs` finds the Audio and narration QA pack from its description. [Search guide](search-and-retrieval.md)

## Reading the snapshot

The inventory covers the six public repositories found under `ta-amps` and every pack directory at [seed revision `24b7d2970`](https://github.com/ta-amps/seed-packs-library-of-nouns-and-verbs/tree/24b7d2970de959cd4b4bdb5c33f6a45cc9c9326b/packs). All 113 manifests declare `proposal_only`. The CSV counts template definitions. The file digests are the upstream manifest values for `nouns.json` and `verbs.json`. The upstream validation report records offline checks and local store probes, with zero production writes or enqueues. Runtime compatibility and individual task outcomes need their own evidence.

For a refresh, enumerate the directories under `packs/` at one commit. Match each directory to its `manifest.json` pack ID and its entry in `packs/VALIDATION.json`. Compare the noun and verb array lengths and the declared file digests before updating counts and links.
